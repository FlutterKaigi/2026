# クイズ大会 当日の運用手順

## 事前準備

1. 対応するFunctions・Firestore Rules・アプリ・ダッシュボードを受付開始前に揃える。
   新しいRulesは旧版アプリの直接書き込みを拒否するため、途中で切り替えず配布版を確認する。
   ローカル検証でもFunctionsを含むエミュレーターを起動する。
2. 運営用の確認済み `@flutterkaigi.jp` アカウントを `admins` に登録する。予備PCでもログインを確認する。
3. 前半・後半の大会を作り、問題・正解・解説を登録する。編集画面を開き直して内容を確認する。
4. 3〜80人・最大20テーブルを準備する。8問を各3分＋読み上げ各1分で実施すると32分かかる。
   説明・移動・表彰を含めて持ち時間に収まるよう問題数・制限時間を確定する。
5. STGで通しリハーサルを行う。本番での練習登録も前後半の参加権を消費する。
   本番で誤登録した場合は初出題前に参加取消する。
6. 受付コードを会場内だけで案内する。コードはチケット本人確認にはならない。
   全体通信障害時に紙回答へ切り替えるか中止するかを事前に決め、記録用紙を用意する。

## 受付・チーム集合

1. 大会を公開し、受付を開始する。ダッシュボードの6桁コードを掲示する。
2. 参加者はサインイン後、表示名とコードを入力する。受理された登録人数を管理画面で確認する。
3. コードが漏れた場合は再発行し、掲示を交換する。登録済みの参加者は影響を受けない。
4. 人数確定後に受付を終了し、チーム編成する。参加者画面の「テーブルN」に集合してもらう。
5. 初出題前なら参加取消・受付再開が可能。どちらも既存のチーム割り当てを解除するため、
   受付終了後に再編成し、参加者へ移動を案内する。
6. 登録済みの遅刻者は割り当て先に合流する。初出題後は新規登録・取消・再編成できない。

通常の「チーム編成」の再実行は既存の割り当てを保持する。
組み直す場合だけ「再編成」を使用する。前半登録者は後半に重複登録できない。

## 出題・回答・結果

1. 「投影画面」を別ウィンドウで開く。プロジェクターに受付コードや管理画面を映さない。
2. 「問題を表示」を押して読み上げる。この間は回答できず、タイマーも進まない。
3. 読み上げ後に「回答開始」を押す。ここから設定した制限時間を数える。
4. チーム内の誰でも回答を変更できる。最後にサーバーが受理した選択肢が最終回答となる。
   参加者には「受理済み」を確認してもらい、送信中・受理未確認のままなら別の端末でも確認する。
5. 締切後に「締切」「正解発表」を操作する。正解発表前なら30秒延長して再受付できる。
   延長しても既存の回答は残る。通信障害時の延長は全チームへ告知する。
6. 正解発表後に次問へ進む。最後の問題の正解発表が終わったら大会を終了する。
   時間超過時は未出題の問題を残して終了できる。確認画面で残り問題数を確認し、出題済み分で集計する。
7. 同率順位は全チーム表示される。入賞3チームへの絞り込みは会場でじゃんけん等を行う。

## 障害時

| 症状 | 対応 |
| --- | --- |
| コードが通らない | 最新コード・6桁入力・受付状態を確認。不正入力が続いた場合は1分待つ |
| 満員または別大会に登録済み | 管理画面で登録一覧を確認。必要なら初出題前に誤登録を取消 |
| 送信結果が確認できない | 通信回復後にチームの回答を確認し、必要なら期限内に再送。運営判断で正解発表前に延長 |
| 時計の同期に失敗 | 通信を確認して再試行。端末時計を変更してもサーバー期限は変わらない |
| 運営操作がタイムアウト | まず状態・期限・チームを確認。同じ画面から再試行する |
| 運営PC故障 | 予備PCで状態を確認して継続。延長・再編成が反映済みか確認してから操作 |
| 全体通信障害 | 決めておいた紙回答・中断手順を実施。未受理の回答を受理済みとして扱わない |

運営操作の重複防止IDは同じ管理画面での再試行に引き継がれる。
画面再読込・別PCでは新しい操作になるため、すでに反映された結果を確認してから押す。
正解発表後の問題訂正、開始後の参加者追加・再編成は提供しない。
誤出題はその問題の扱いを運営が判断し、通常運用でFirestoreを直接編集しない。

## リハーサルで確認すること

- 80人の定員境界、前後半の重複参加、コード更新後の旧コード拒否。
- 複数運営端末からの同時操作、古い問題編集画面での保存拒否。
- 読み上げ→開始→締切→延長→正解発表→終了の通し進行。
- チーム複数端末での回答変更、締切直前の通信断と再接続、アプリ再起動。
- 端末時計がずれた状態、バックグラウンド復帰時の残り時間。
- 同率順位、遅刻者のテーブル表示、投影画面に受付コード・未公開正解が出ないこと。
- 実機のApp Check、会場Wi-Fi、予備PC、司会を含む所要時間。
